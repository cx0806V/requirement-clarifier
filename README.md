# 需求澄清器

> **说清想法，就能让 AI 干活。** 你写一句大白话 → 几个问题把需求问清楚（每题都有现成答案可选）→ 生成一段可以直接粘给任何 AI 的需求。

![需求澄清器：首页（两种模式）](screenshot.png)

## 两种模式（v0.2 新增）

| 模式 | 给谁用 | 问几题 | 输出 |
|---|---|---|---|
| **半开发者** | 会用 AI，但说不清需求 | 8 题 | 结构化需求说明 + 执行要求 + 自检清单 |
| **零基础** | 从没用过 AI | 5 题 | 一段能直接发给 AI 的话 |

选过的模式会被记住（只存在你自己的浏览器里）。

## 功能（v0.2）

- **两种模式可切换**：零基础只问 5 题、每题都有现成答案；半开发者问 8 题、输出结构化需求
- **全部改成大白话**：界面不再出现「可执行 / 交付物 / 硬约束 / 反例 / 验收标准 / 迭代计划」这类术语
- **每题给 2–4 个现成答案**：点选即可，也可以自己写
- **必填项拦截**：目标、交付物、验收标准没填清，不生成结果
- **一键复制**：生成结果自带「执行要求」和「自检清单」
- **完整度提示**：结果页告诉你 AI 可能还会追问哪几项
- **「返回修改」**：生成后不用从头再来
- **「先让 AI 来问我」**：直接生成一段澄清提示词，粘给豆包 / DeepSeek，让 AI 反过来问你
- **示例按钮**：不知道第一句写什么，点一个现成的
- **关键词提示**：检测到 PPT / 代码 / 文案，自动提示该补什么
- **不联网、不上传、无后端**：纯前端，数据只存在你自己的浏览器里
- **手机可用**

## 本地使用

双击 `index.html` 即可（不需要安装任何东西）。

## 测试

```bash
node tests/smoke.test.mjs
```

29 项冒烟测试（零依赖，本地极简 DOM 模拟）：覆盖两种模式完整流程、必填拦截、返回修改、模式记忆、复制提示、示例填充。

## 技术

纯 HTML + CSS + 原生 JavaScript，零依赖、零构建、单个页面。

```
index.html   页面结构
style.css    样式（移动端适配）
app.js       追问、模式切换、校验、生成、复制
tests/       冒烟测试
```
