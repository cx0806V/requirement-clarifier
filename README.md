# 需求澄清器

> **把模糊需求，问成「AI 能执行、你能验收」的提示词。**

你写一句大白话 → 8 个问题把需求问清楚（每题都给推荐答案）→ 生成一段可以直接粘给任何 AI 的需求提示词。

## 功能（v0.1）

- **8 步追问向导**：目标 / 受众 / 输入 / 交付物 / 硬约束 / 反例 / 验收标准 / 迭代计划
- **每题给 2–4 个推荐答案**（点选即可，也可以自己写）
- **必要项拦截**：目标、交付物、验收标准没填清，不生成结果
- **一键复制**：生成的需求提示词自带「执行要求」和「自检清单」
- **「先让 AI 来问我」**：不走向导，直接生成一段澄清提示词，复制粘给豆包，让 AI 反过来问你
- **关键词智能提示**：检测到 PPT / 代码 / 文案，自动提示该补什么
- **不联网、不上传、无后端**：纯前端，数据只存在你自己的浏览器里
- **手机可用**

## 本地使用

双击 `index.html` 即可（不需要安装任何东西）。

## 在线使用

部署 GitHub Pages 后可直接访问：`https://cx0806V.github.io/requirement-clarifier/`
（若打开是 404，说明 Pages 还没开启：仓库 Settings → Pages → 选择 main 分支 / root → Save）

## 技术

纯 HTML + CSS + 原生 JavaScript，零依赖、零构建、单个页面。

```
index.html   页面结构
style.css    样式（移动端适配）
app.js       8 项追问、校验、提示词生成、复制
```
