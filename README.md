# 需求澄清器

## 这是什么
把一段大白话需求，通过 8 个固定问题的追问补全，生成一段可以直接粘给任何 AI 的提示词。

## 为什么做
我用 AI 干活时最烦的是「说不清 → 反复重来」：24 份问卷里有 50% 的人靠「换个说法再问一遍」硬扛。我想把这一步自动化。

## 最小功能（v0.1）
- [ ] 大白话输入
- [ ] 8 项追问
- [ ] 生成可复制的提示词
- [ ] 缺项标红
- [ ] 网页可直接打开

## 怎么用
1. 打开网页，用一句话写下你要做的事
2. 按提示回答 8 个问题
3. 复制生成的提示词，粘给豆包、DeepSeek 等任意 AI
